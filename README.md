# Sistema de Biblioteca Digital

## Integrantes
- Carlos Reyes Alvear Herrera
- Jesica Rodríguez

## Objetivo
Proponer un sistema de biblioteca digital que facilite la organización de libros, el registro de usuarios y el control de préstamos y devoluciones.

## Descripción
Este proyecto académico busca organizar la información de una biblioteca mediante una propuesta de sistema sencilla y fácil de utilizar. El trabajo se desarrolla aplicando conceptos de gestión de configuración y calidad del software en GitHub.

## Funcionalidades principales
1. Registrar libros en el catálogo.
2. Buscar libros por título, autor o categoría.
3. Registrar usuarios.
4. Registrar préstamos de libros.
5. Controlar las devoluciones y disponibilidad.

## Usuarios del sistema
- Administrador: gestiona el catálogo y los registros.
- Bibliotecario: registra préstamos y devoluciones.
- Lector: consulta los libros disponibles.

## Requisitos del sistema
- RF-01: El sistema debe permitir registrar libros con título, autor y categoría.
- RF-02: El sistema debe permitir buscar libros en el catálogo.
- RF-03: El sistema debe permitir registrar usuarios.
- RF-04: El sistema debe permitir registrar préstamos asociados a un usuario.
- RF-05: El sistema debe permitir registrar devoluciones y actualizar la disponibilidad de los libros.

## Herramienta de gestión
GitHub se utilizará para documentar el proyecto, registrar cambios mediante commits, trabajar con ramas y revisar propuestas mediante Pull Requests.

## Alcance
Esta actividad consiste en planificar y documentar el proyecto. No incluye la programación ni el desarrollo de una aplicación.
